## 3. 택배 운영 규칙 (자주 묻는 것)

- **당일 출고 기준: 오후 4시 30분 결제건까지** (셀리오랩 26-10-23)
- 분실 보상 금액은 **상품가에서 부가세를 뺀 금액**으로 공제 (마라나타)
- **포장 미비로 인한 파손은 택배사 접수 불가** (혜보리빙)
- 네이버 자동수거 반품은 해당 날짜에 반품지로 설정된 곳으로 수거됨. 수거 실패 시 물류업체에 이름·주소·전화번호·상품명을 주고 재접수 (다혜 26-10-21)
- **택배 픽업 마감**: 평소 발주 2시까지 → 픽업 4시 마감, 긴급건은 3시까지 (부쉬맨). 마감 일찍 끝나는 날은 15시 (베베푸우 26-02-18). 슈돌츠 등은 4:30 발주 마감, 5:30~6시 픽업 (부쉬맨 25)
- 명절·택배없는날 전후로는 마감이 앞당겨짐. 그때마다 공지 (2026 추석 공지: 탑펫 고한솔 26-09-17)
- 픽업 전까지는 **발송 취소 가능**. 송장 출력 이후에 들어온 취소는 따로 요청해야 함 (부쉬맨 24-07-08)
- 출고된 뒤에는 취소 불가 (베베푸우 23-01-03)
- 배송 중 **주소 변경**은 기사·대리점이 달라 대부분 불가 (슈돌츠 21-07). 대안은 새 주소로 재발송 + 반송 처리. 지연으로 인한 반송은 택배비 미청구 (베베푸우 21-11)
- **외부 주소 → 외부 주소 반품 불가**. 우리 창고로 회수한 뒤 재발송 (김진수 26-10-26)
- 반품은 주소를 바꿔도 **코드 기준으로 우리 창고에 들어오는 경우가 많음** (부쉬맨 24-01)
- **안심번호 만료** 고객: 회수·연락 불가 → 안심번호 재발급이나 실제 번호 필요. 반품·취소를 처리해야 새 안심번호 발급 가능 (롯데 25-02, 베베푸우)
- 반품 수거 현황: 기사가 송장을 출력하면 송장번호가 발번되어 조회 가능 (썸머 26-03-13)
- CJ는 박스 포장이 안 된 반품은 수거를 안 하는 경우가 있음 (휴리즈 26-10-22)
- 교환은 **회수 확인 후 출고**: 선출고하면 출고품이 회수되는 사고가 있었음 (부쉬맨 26-11-03)
- 보상: 발송 후 **영업일 5일 이상 지연이면 배송비 보상 가능** (베베푸우 22-03). 파손이면 회수가 필요하고, 파손 처리되면 배송비·반품비 무료 (베베푸우 21-08). 택배사 보상은 택배사가 물건을 사는 형태라 원칙상 폐기 건은 불가, 개별 조율 (탑펫 26-08-05)
- 파업·배송불가로 돌아온 건은 **미청구**. 재발송은 보상 대상이 아님 (슈돌츠 22-03)
- 오배송 건: 왕복 택배비를 마감에서 공제하고, 물품가액도 공제 (탑펫·베베푸우)
- 이전 주소로 오발송된 건은 새로 발송 (베베푸우 22-12)

## 4. 쿠팡 (로켓그로스·로켓배송·밀크런)

- **로켓그로스/쉽먼트 발송 기준: 입고예정일 기준 영업일 4일 전부터 출고 가능** (그 이전 출고 시 기준일 오류). 예: 8일 입고 → 4일 발송, 5일 도착 (부쉬맨)
- 로켓배송은 +4영업일 기준으로, 오늘은 그 날짜 발주건까지만 발송 가능 (부쉬맨 26-01). 마감된 발주일자는 발송 불가 → 다음 일자로 확정 (슈돌츠 26-01, 26-04)
- 입고예정일 -4일 기준을 넘기면 **회송** 대상 (부쉬맨 25-02)
- **밀크런**: 픽업 **전일 오후 2시** 마감 (D-2 예약 마감인 경우도 있음). 같은 픽업일에 같은 센터 밀크런은 중복 접수 불가 → 쉽먼트로 (구오 24-02, 24-05). 배차 마감은 당일 1시인 경우도 있음

- 센터 마감은 **실시간**이라 변경 즉시 접수하는 수밖에 없음 (부쉬맨 24-08)
- 같은 날짜가 아니면 합쳐지지 않고, 송장번호도 중복 입력 불가 (부쉬맨 24-11)
- 밀크런 혼적: 120개까지 혼용 가능, 10개 단위면 혼용 OK (씨드 26-09-11)
- 밀크런 출고지 등록: 윙 → 입고관리 → 입고생성 → 입고방법 '밀크런' → 출고지 '+새주소추가' → 승인 후 생성. **오전에 신청하고 오후까지 승인이 안 나면 당일 생성 불가** (씨드 26-01-06)
