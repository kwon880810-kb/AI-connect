# 화면 흐름도

> 작성 2026-11-05. `BM_확정안.md`를 화면과 진행 상태로 옮긴 것입니다. 이 문서가 확정되면 Supabase 구조(테이블·권한)와 화면 작업의 기준이 됩니다.

---

## 1. 전체 화면 지도

```
[모두]
 ├ 홈 ............................ 서비스 소개, 분야별 진행 중 의뢰 수, 등록 공급사 수
 ├ 공급사 둘러보기 ................ 가린 프로필 목록 / 상세 → (수요자) 찜 → 지정 의뢰
 ├ 이용 안내·요금 ................ 일반 의뢰 / 지정 의뢰 요금표, 환불 기준, FAQ
 ├ 회원가입 ...................... 수요자 / 공급자 선택
 └ 약관 · 개인정보처리방침

[수요자]
 ├ 의뢰하기 ...................... 일반 의뢰 / 지정 의뢰
 └ 내 프로젝트
     ├ 의뢰 목록 (상태별)
     └ 의뢰 상세: 요청 내용 · 첨부 파일 · 공급자 리스트(비교표) · 이의신청 · 기본계약서

[공급자]
 └ 공급자 센터
     ├ 맞는 의뢰 목록 (분야 필터, 썸네일 1개)
     ├ 의뢰 상세 → 체크리스트 응답
     ├ 내 응답 (상태: 제출 / 선정 / 미선정)
     ├ 의견서 요청함
     ├ 기본계약서
     ├ 내 프로필 (둘러보기에 보이는 모습 미리보기)
     └ 내 신뢰도 점수 (본인만)

[관리자 = 브로커]
 ├ 의뢰 관리: 응답 모아 보기 → 순위 → 검증 → 선정 → 리스트 전달
 ├ 비회원 공급자 대리 입력
 ├ 이의신청 · 의견서 · 판정 · 환불 처리
 ├ 공급자 관리: 사업자 확인, 인허가 서류 확인, 신뢰도 점수
 ├ 분류 관리: 대분류·중분류·조건값·공정·별칭·헷갈리기 쉬운 점, 분류 변경 기록
 └ 계약서 보관함
```

## 2. 수요자: 일반 의뢰

```
의뢰하기
 ① "만들고 싶은 것" 입력 → 별칭으로 분류 추천 (예: "츄르" → 반려동물 > 간식)
 ② 대분류 확정 (필수) / 중분류 선택 (선택, 무료)
     └ 헷갈리기 쉬운 점 안내 표시 (예: "펫 간식은 사료제조업 등록 공장이 필요합니다")
 ③ 필수값 입력: 수량·단가·납기 범위, 샘플 필요 여부, 납품지
 ④ 조건값 선택 (각 +5,000원), 권장 조건값(인허가 서류 확인) 표시
 ⑤ 받을 업체 수 (기본 2곳, 추가 1곳당 +20,000원)
 ⑥ 상세 설명 + 첨부 파일 (파일마다 모두 공개 / 선정사 공개)
 ⑦ 금액 확인 → 약관·환불 기준 동의 → 카드 결제
     └ 회원이 아니면 이 단계 전에 가입
 ⑧ 결제 완료 → 내 프로젝트로 이동
```

## 3. 수요자: 지정 의뢰 (착수금 절반)

```
공급사 둘러보기 → 마음에 드는 공급사 "찜" (여러 곳)
 → "찜한 공급사에게 의뢰하기"
 → 위 ①~⑥과 같음 (업체 수 = 찜한 공급사 수, 추가 1곳당 +10,000원)
 → 금액 확인: 착수금 25,000원 + 조건값 + 업체 추가
 → 결제 → 지정한 공급사에게만 요청서 전달
 → 지정 공급사가 체크리스트를 확인하고 응답 (48시간)
     · 필수값이 맞음 → 그 업체분 결제 확정, 리스트에 올라감
     · 필수값 불일치(✕) → 그 업체분 환불
     · 48시간 안에 응답 없음 → 그 업체분 환불
 → 리스트 전달 후에는 일반 의뢰와 같은 검증기간 7일
```

## 4. 의뢰 진행 상태

```
          ┌──────────────────────── 일반 의뢰 ─────────────────────────┐
결제완료 → 공개(응답 받는 중, 48시간) → 선정 중(브로커) → 리스트 전달 ─┐
          └─ 지정 의뢰 → 지정사 응답 대기(48시간) ─────→ 리스트 전달 ─┤
                                                                   ▼
                                                        검증기간 (7일)
                                                     ┌─────┴─────┐
                                                 이의 없음      이의신청
                                                     │             ▼
                                                     │    의견서 요청(공급자, 3영업일)
                                                     │             ▼
                                                     │         운영자 판정
                                                     │      ┌──────┴───────┐
                                                     │   인정            불인정
                                                     │   ▼                 │
                                                     │ 수요자 선택:        │
                                                     │ 환불 / 대체 업체    │
                                                     ▼                     ▼
                                                   확정 ◀──────────────────┘
                                                     ▼
                                      (선택) 기본계약서 작성 → 양쪽 서명 → 보관
```

| 상태 | 수요자 화면 | 공급자 화면 | 관리자 할 일 |
|---|---|---|---|
| 결제완료 | "공급자에게 공개 중" | – | – |
| 공개 | **열람·응답 현황**만 보임 (예: "열람 1,000 / 응답 100 · 응답률 10%"), 내용은 안 보임 | 의뢰 목록에 노출, 응답 가능 | 응답 부족하면 비회원 수배·대리 입력 |
| 선정 중 | "업체 선정 중" + 열람·응답 현황 | 응답 마감 | 순위 확인, 검증, 선정 |
| 리스트 전달 | 리스트·비교표·연락처, 이의신청 버튼, 남은 검증일 | 선정 / 미선정 알림, 선정되면 수요자 연락처는 여전히 비공개 | – |
| 이의 접수 | 처리 중 | 의견서 요청 | 판정 |
| 확정 | 계약서 작성 버튼 | 계약서 작성 버튼 | 정산 |

## 5. 공급자 흐름

```
회원가입 → 사업자등록번호 확인(국세청) → 분야·중분류·공정·보유 인허가 선택 → 프로필 작성
 → 맞는 의뢰 알림
 → 의뢰 목록 (썸네일 1개, 분야, 품목, 수량 범위, 마감까지 남은 시간)
 → 의뢰 상세 (수요자 정보 가림, 공개 범위에 맞는 첨부 파일만)
 → 체크리스트 응답
     · 범위 항목: 수량·단가·납기 범위 입력 → ●/▲/✕ 자동 표시
     · 선택 항목: ● 가능 / ▲ 조건부(조건 메모 필수) / ✕ 불가
     · 인허가 보유 서약 체크
 → 제출 → 선정되면 알림 (수요자가 연락해 옴)
```

## 6. 첨부 파일 공개 규칙

| 보는 사람 | 모두 공개 파일 | 선정사 공개 파일 |
|---|---|---|
| 비회원 | ✕ | ✕ |
| 공급자 회원 (목록) | 썸네일 1개 (첫 번째 모두 공개 파일) | ✕ |
| 공급자 회원 (상세) | ○ | ✕ |
| 선정된 공급자 / 지정 공급자 | ○ | ○ |
| 수요자 본인, 관리자 | ○ | ○ |

- 모두 공개 파일이 없으면 썸네일은 분야 기본 이미지를 씁니다.
- 수요자는 의뢰 상세에서 파일별 공개 범위를 **나중에 바꿀 수 있습니다** (선정 전까지).

## 결정 사항 (2026-11-05)
1. **지정 의뢰**: 지정 공급사가 체크리스트를 확인해서 맞으면 그 업체분 결제 확정, 필수값이 맞지 않으면 그 업체분 환불. 리스트 전달 뒤에는 일반 의뢰와 같은 7일 검증을 적용합니다.
2. **지정 공급사 무응답 (48시간)**: 그 업체분 환불.
3. **응답 현황 표시**: "열람 1,000 / 응답 100 · 응답률 10%" 형태. 열람 = 의뢰 상세를 연 공급자 수, 응답 = 체크리스트를 제출한 공급자 수.
