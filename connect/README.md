# 윈-윈 커넥트 홈페이지

소량 제작이 필요한 사업자(수요자)와 공장(공급자)을 연결하는 서비스입니다. 정적 웹사이트 + Supabase(회원·데이터·파일)로 동작하고, 휴대폰에서 앱처럼 설치(PWA)할 수 있습니다.
사업 구조는 `BM_확정안.md`, 화면 흐름은 `화면_흐름도.md`를 기준으로 합니다.

## 화면
| 파일 | 누가 | 내용 |
|---|---|---|
| `index.html` | 모두 | 소개, 분야별 진행 건수, 요금, 환불 기준, FAQ |
| `login.html` | 모두 | 로그인 / 회원가입 (수요자·공급자 선택) |
| `directory.html` | 모두 | 공급사 둘러보기 (업체명·연락처 가림), 찜 → 지정 의뢰 |
| `request.html` | 수요자 | 의뢰하기: 분류 추천, 범위 입력, 추가 조건, 파일 공개 범위, 금액 자동 계산 |
| `projects.html` | 수요자 | 내 프로젝트: 입금 안내, 응답 현황(열람·응답·응답률), 공급자 리스트, 이의신청 |
| `supplier.html` | 공급자 | 공급자 센터: 회사 정보·사업자번호, 의뢰 목록, 체크리스트 응답, 내 응답, 의견서, 내 신뢰도 |
| `admin.html` | 관리자 | 입금 확인, 응답 순위·대리 입력, 선정·리스트 전달, 확정, 공급자 사업자 확인, 이의 판정, 요금 설정 |
| `terms.html`, `privacy.html` | 모두 | 이용약관(초안), 개인정보처리방침 |

공통 파일: `js/config.js`(상호·연락처·Supabase 주소), `js/sb.js`(로그인·메뉴·공통 기능), `css/style.css`, `vendor/supabase.js`(Supabase 공식 라이브러리 v2.45.4, MIT).

## 지금 동작 방식 (PG 연동 전)
1. 수요자가 의뢰를 접수하면 금액이 확정되고 "입금 대기"가 됩니다. 입금 안내 문구는 `js/config.js`의 `bankInfo`에서 바꿉니다.
2. 관리자가 입금을 확인하고 **입금 확인**을 누르면 공급자에게 공개되고 48시간 응답을 받습니다.
3. 관리자가 순위를 보고 업체를 골라 **리스트 전달** → 수요자에게 연락처 공개, 7일 검증기간 시작.
4. 이의신청 → 관리자가 의견서 요청 → 공급자 의견 → 판정(환불/대체, 공급자 책임이면 신뢰도 차감).
5. 검증기간이 끝나면 관리자가 **확정**을 누릅니다.
6. 환불은 실제로 송금·카드 취소를 한 뒤 관리자 화면에 기록합니다.

## 미리 보기
아무 정적 서버로 열면 실제 Supabase에 연결됩니다.
```bash
cd connect && python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다. 관리자는 대표님 계정(kwon880810@gmail.com)으로 로그인하면 됩니다.

## 배포 전에 Supabase에서 할 것
Supabase 대시보드 → **Authentication → URL Configuration**
- **Site URL**: 실제 홈페이지 주소 (예: `https://connect.kblogistics.kr`)
- **Redirect URLs**: 같은 주소 추가 (가입 확인 메일의 링크가 이 주소로 돌아옴)

**Authentication → Emails**: 무료 기본 메일 발송은 **시간당 몇 통으로 제한**됩니다. 회원이 늘기 전에 SMTP(예: 네이버웍스, Gmail, Resend)를 연결하세요. 테스트할 때는 "Confirm email"을 잠시 꺼 두면 가입 즉시 로그인됩니다.

## 배포 (무료)
`connect` 폴더 전체를 올리면 됩니다: Netlify(폴더 끌어다 놓기), Cloudflare Pages, GitHub Pages 중 하나.
파일을 고쳐 다시 배포할 때는 `sw.js`의 `VERSION`을 올려 주세요.
