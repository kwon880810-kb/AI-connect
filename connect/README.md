## 지금 동작 방식 (PG 연동 전)
1. 수요자가 아이디어를 **출시 프로젝트**로 작성합니다(자동 저장). 차수(1차~4차)마다 필요한 단계만 골라 접수합니다.
2. 접수하면 서버가 요금을 정합니다: 첫 파트너 찾기는 **접수비 9,900원**(쿠폰이면 0원), 이어하기는 9,900원 + 추가 요금, 기존 파트너 문의는 0원. 입금 안내 문구는 `js/config.js`의 `bankInfo`.
3. 관리자가 입금(또는 0원 의뢰)을 확인하고 **공개 승인**을 누르면 파트너에게 공개되고 48시간 응답을 받습니다. 쿠폰 의뢰는 전화로 진지한 의뢰인지 확인 후 공개.
4. 관리자가 순위를 보고 업체를 골라 **리스트 전달**:
   - 첫 파트너 찾기면 **착수금 입금 대기** → 수요자는 업체명 없이 체크 결과만 봄 → 관리자가 **착수금 입금 확인** → 연락처 공개, 7일 검증 시작
   - 이어하기·기존 파트너 문의면 바로 연락처 공개
5. 이의신청 → 의견서 요청 → 파트너 의견 → 판정(환불/대체, 파트너 책임이면 신뢰도 차감).
6. 검증기간이 끝나면 관리자가 **확정**을 누릅니다. 환불은 송금·카드 취소 후 관리자 화면에 기록.
7. 요금·쿠폰 지급 여부·기간은 관리자 화면 **요금 설정**에서 바꿉니다 (`coupon_active` 1=지급, 0=중단).

## 미리 보기
아무 정적 서버로 열면 실제 Supabase에 연결됩니다.
```bash
cd connect && python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 을 엽니다. 관리자는 대표님 계정(kwon880810@gmail.com)으로 로그인하면 됩니다.

## 배포 전에 Supabase에서 할 것
Supabase 대시보드 → **Authentication → URL Configuration**
- **Site URL**: 실제 홈페이지 주소 (예: `https://connect.kblogistics.kr`)
- **Redirect URLs**: 같은 주소 추가 (가입 확인 메일의 링크가 이 주소로 돌아옴)

**Authentication → Emails**: 무료 기본 메일 발송은 **시간당 몇 통으로 제한**됩니다. 회원이 늘기 전에 SMTP(예: 네이버웍스, Gmail, Resend)를 연결하세요. 테스트할 때는 "Confirm email"을 잠시 꺼 두면 가입 즉시 로그인됩니다.
