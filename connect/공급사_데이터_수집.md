# 비회원사(공급사) 데이터 수집 기준

작성일: 2026-11-05 · 운영: KB물류

회원 공급자가 모이기 전에 **공공데이터**와 **운영사 네트워크(대표님 인맥)** 로 공급사를 미리 등록합니다.
'제작 파트너 둘러보기'에 **비회원사**로 보이고, 의뢰가 들어오면 운영사가 전화로 확인한 뒤 대리 입력합니다.

## 1. 정해진 규칙 (2026-11-05)

| 항목 | 내용 |
|---|---|
| 수집 출처 | 공공데이터, 운영사 네트워크 두 가지만. 크롤링이나 다른 플랫폼 목록 복사는 하지 않음 |
| 공개 범위 | 종류 배지(제조 공장/디자이너/인증 대행사 등), 지역, 분류, 공정, 소개, 출처 구분만 공개. **업체명·연락처·사업자번호는 비공개** |
| 표시 | 회원사는 "회원사 · 사업자 확인", 비회원사는 "비회원사 · 공개 정보 기반" 또는 "비회원사 · 운영사 네트워크". 활동을 확인한 곳은 "활동 확인" 배지 추가 |
| 지정 의뢰 | 지금은 **꺼짐**. 관리자 → 요금 설정 → `direct_request_enabled` 를 1로 바꾸면 켜짐. 켜도 **비회원사는 지정할 수 없음** (DB에서 막음) |
| 회원 전환 | 같은 사업자번호로 회원가입하면 자동으로 회원사에 연결되고, 비회원사 목록에서는 내려감 |
| 제외 요청 | 업체가 빼 달라고 하면 '업체 의사'를 **제외 요청**으로 바꿈. 바로 숨겨지고, CSV를 다시 올려도 공개되지 않음 |
| 공지 문구 | 둘러보기 화면에 "비회원사는 공개 정보를 바탕으로 정리한 업체이며 윈-윈 커넥트와 제휴 관계가 아님", 제외 요청 메일 주소 표시 |

## 2. 처음 넣을 범위 (추천)

공장은 너무 많으니 **첫 고객이 실제로 의뢰할 분야**부터, **활동이 확인되는 곳만** 넣습니다.
지역은 **수도권(경기·인천·서울) 우선**입니다. 파주에서 방문하거나 샘플을 받기 쉽기 때문입니다.

### 1순위: 공공데이터로 바로 모을 수 있는 제조 공장

| 우선 | 대분류 > 중분류 | 종류 배지 | 공공데이터 (이름은 **확인 필요**) | 목표 수 |
|---|---|---|---|---|
| ① | 반려동물용품 > 간식, 사료 | 제조 공장 | 사료제조업 등록 현황 (농림축산식품부·지자체) / 식품제조가공업(반려동물 간식을 식품 공장에서 만드는 경우) | 30~50곳 |
| ② | 식품 OEM > 과자·베이커리·떡, 소스·양념·드레싱, 분말·건조·차, 잼·청·장류·절임 | 제조 공장 | 지방행정 인허가 데이터(LOCALDATA) '식품제조가공업' / 식품안전나라 인허가 업소 정보 | 50~100곳 |
| ③ | 패키지·인쇄 > 파우치·포장 필름, 단상자, 스티커·라벨 | 인쇄·포장재 | 팩토리온 '전국 공장 등록 현황'(업종: 포장재·인쇄) / LOCALDATA '인쇄사' | 20~30곳 |
| ④ | 화장품 | 제조 공장 | 식약처 '화장품 제조업 등록 현황' | 2차에 |
| ⑤ | 생활·잡화, 부자재·판촉물 | 제조 공장 | 팩토리온 '전국 공장 등록 현황' | 2차에 |

### 2순위: 운영사 네트워크 중심

| 대분류 | 종류 배지 | 방법 |
|---|---|---|
| 디자인 (포장·로고·라벨) | 디자이너 | 대표님 인맥. **사업자등록한 프리랜서·스튜디오만** |
| 촬영·상세페이지 | 촬영·상세페이지 | 대표님 인맥 |
| 표시사항·인증 대행 | 인증 대행사 | 대표님 인맥 + 거래해 본 대행사 |
| 포장·조립·키팅, 물류 | 포장·조립 / 3PL | KB물류와 협력사. 3PL은 대표님 경험 소개만 하기로 했으므로 목록에는 필요할 때만 |

> 공공데이터 이름과 위치는 2026-11-05 기준 확인하지 못했습니다. 실제로 받기 전에 공공데이터포털(data.go.kr), LOCALDATA(localdata.go.kr), 식품안전나라, 팩토리온에서 이름과 항목을 확인해 주세요.

## 3. 활동 확인 기준 (공개 전에 하나 이상)

1. **영업 상태**: 인허가 데이터의 영업상태가 '영업/정상'이고, 국세청 사업자등록 상태조회에서 **계속사업자**
2. **최근 활동**: 최근 1년 안에 품목제조보고·인허가 변경 기록이 있음
3. **온라인 흔적**: 홈페이지, 스마트스토어, OEM 소개 글 중 하나가 살아 있음
4. **전화 확인**: 전화를 받고 OEM·소량 생산 가능 여부를 들음 → 이때 **'오늘 활동 확인'** 을 누름

1번만 맞으면 공개해도 되고, 3번이나 4번까지 맞으면 "활동 확인" 배지가 붙습니다. 활동 확인일이 1년이 넘은 곳은 다시 확인합니다.

## 4. CSV 양식

관리자 → **비회원사** 탭 → `CSV 양식` 으로 받아서 채운 뒤 `CSV 올리기`.
엑셀에서 저장할 때는 **CSV UTF-8** 로 저장하세요.

| 열 | 필수 | 쓰는 법 |
|---|---|---|
| 업체명 | ✓ | 비공개. 관리자만 봄 |
| 사업자번호 | | 숫자 10자리 (하이픈 있어도 됨). **같은 번호가 이미 있으면 갱신**, 없으면 추가 |
| 분류 | | `대분류>중분류` 를 `;` 로 구분. 예: `식품 OEM>과자·베이커리·떡;포장·조립·키팅`. 대분류 이름만 써도 됨. 모르는 이름은 결과에 알려 줌 |
| 공정 | | `;` 로 구분. 예: `배합;살균;파우치 충전` |
| 지역 | | 시·도 (경기, 경기도 모두 가능) |
| 소개 | | **공개됨**. 업체명·전화번호를 쓰지 마세요 |
| 담당자, 연락처 | | 비공개 |
| 출처구분 | | `공공데이터` 또는 `네트워크`(인맥) |
| 출처명 | | 예: `식약처 식품제조가공업 인허가` (공공데이터는 꼭 적기) |
| 수집일, 활동확인일 | | `2026-11-05` 또는 `2026.11.05` |
| 공개 | | `Y` / `N` (비우면 공개) |

분류 이름(현재):

- 식품 OEM: 소스·양념·드레싱 / 분말·건조·차 / 음료·액상차·즙 / 과자·베이커리·떡 / 캔디·젤리·초콜릿 / 육가공·수산가공 / 간편식·냉동·밀키트 / 잼·청·장류·절임 / 건강기능식품 / 소분·재포장
- 반려동물용품: 간식 / 사료 / 영양제·보조제 / 위생·케어 / 배변·위생 소모품 / 장난감 / 스크래쳐·캣타워 / 의류·리드줄·하네스 / 하우스·방석·쿠션 / 식기·급수기 / 이동·외출용품
- 패키지·인쇄: 택배 박스 (골판지) / 단상자 (판지) / 싸바리·하드케이스 / 스티커·라벨 / 롤 라벨 / 파우치·포장 필름 (연포장) / 쇼핑백 / 인쇄물 / 인쇄 테이프
- 화장품 / 생활·잡화 / 부자재·판촉물 / 포장·조립·키팅
- 물류 (보관·출고): 3PL 보관·출고 / 소량 택배 발송
- 디자인: 포장 디자인 / 로고·브랜딩 / 라벨·스티커 디자인
- 촬영·상세페이지: 제품 촬영 / 상세페이지 제작 / 영상 제작
- 표시사항·인증 대행: 식품 표시·품목제조보고 / KC 인증 / 화장품 표시·책임판매 / 생활화학제품 신고 / 사료 성분 등록·표시

## 5. 법적으로 조심할 점 (변호사 확인 권장)

- 공공데이터는 각 데이터의 **이용허락 조건**(공공누리 유형)을 확인하고 출처명을 적습니다. 출처 표시가 필요한 유형이면 둘러보기 화면의 '공개 정보 기반' 표시와 이 문서의 출처명으로 남깁니다.
- 개인사업자의 이름·전화번호는 개인정보가 될 수 있습니다. 그래서 **화면에 공개하지 않고**, 운영사가 가능 여부를 묻는 연락에만 씁니다. 업체가 거절하면 바로 '제외 요청'으로 바꿉니다.
- 첫 통화에서 "윈-윈 커넥트에 비회원사로 소개해도 되는지" 묻고, 동의하면 '노출 동의'로 바꿉니다.
- 제휴·인증·추천처럼 보이는 표현은 쓰지 않습니다. 비회원사는 "운영사가 대신 확인"으로만 표시합니다.
