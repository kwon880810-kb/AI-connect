## 1. 한 줄 정의
**브로커가 수요자의 일(업체 찾기·확인)을 대신해 주고 수요자에게 정보값을 받는 서비스.** 공급자는 선정되어 일을 받는 쪽이며, 공급자에게는 돈을 받지 않습니다.

| 참여자 | 역할 | 돈 |
|---|---|---|
| **수요자** | 요청서 작성 (분류, 필수값, 조건값, 업체 수) | 착수금 + 추가요금 **냄** |
| **공급자 (회원)** | 가입, 맞는 의뢰 확인, 체크리스트 직접 응답 | **무료** |
| **공급자 (비회원)** | 의뢰를 볼 수 없음. 브로커가 대신 확인하고 응답을 입력 | 무료 |
| **윈-윈 커넥트 (브로커)** | 의뢰 공개, 응답 검증, 상위 업체 선정, 리스트 전달, 불일치 처리 | 수요자 요금 수령 |

**공급자에게 돈을 받지 않는 이유**: 공급자가 내는 비용은 결국 단가에 얹히고, 소형 거래일수록 영향이 큽니다. 우리 때문에 단가가 오를 이유를 최소화합니다.
- 공급자 성사 수수료(기존 10만 원)는 **폐지**
- 공급자 구독료·이용료는 공급자가 충분히 모이기 전까지 **받지 않음**. 나중에 받게 되면 건당이 아닌 **고정 월정액**으로 검토 (단가 영향 최소화)

## 2. 수요자 요금

수요자가 내는 돈은 **정보값**입니다. 업계 종사자는 전화 한두 통으로 아는 값을, 업계 밖 사람은 오래 찾아야 알 수 있습니다. 그래서 **거래 성사 여부와 상관없이** 받습니다.

| 구분 | 내용 | 금액 |
|---|---|---|
| **착수금 (기본)** | 업체 **2곳**, 해당 분류의 **필수값** 전부 | **50,000원** |
| 조건값 추가 | 필수 외 조건값 1개당 | **+5,000원** (전부 동일, 세부 조정은 추후) |
| 중분류 선택 | 품목 범위 좁히기 | **무료** |
| 인허가 서류 확인 (권장 조건값) | 중분류에 법적으로 필요한 인허가를 서류로 확인 | +5,000원 |

**지정 의뢰 (브로커를 거치지 않음)**
수요자가 "공급사 둘러보기"에서 고른 공급사에게만 요청서를 보내는 방식입니다. 브로커가 고르지 않으므로 **착수금이 절반**입니다.

| 구분 | 일반 의뢰 | 지정 의뢰 |
|---|---|---|
| 착수금 | 50,000원 | **25,000원** |
| 조건값 | 1개당 5,000원 | 1개당 5,000원 (**같음**) |
| 업체 추가 | 1곳당 20,000원 [예시] | 1곳당 10,000원 [예시, 절반 적용] |
| 업체 선정 | 브로커가 순위·검증 후 선정 | 수요자가 직접 고름 |
| 공급사 응답 단계 | – | 지정 공급사가 체크리스트를 확인해 **맞으면 그 업체분 결제 확정, 필수값 불일치면 그 업체분 환불** |
| 48시간 무응답 | – | **그 업체분 환불** |
| 리스트 전달 후 | 검증 7일 | 검증 7일 (같음) |

**업체분 환불액**: 결제금액 × (환불 업체 수 ÷ 지정한 업체 수)
| 업체 추가 | 3곳째부터 1곳당 | +20,000원 **[예시]** |

- 요청서 화면에서 금액이 자동으로 계산되어 보입니다.
- 부가세 포함/별도는 세무사 확인 후 표기합니다. (미정)

## 3. 결제 · 거래확정 · 환불

### 결제
- **카드 결제 후 조건부 환불(부분취소)**, PG사 이용
- 의뢰할 때 결제합니다. 화면에는 "에스크로" 대신 **"조건 미충족 시 환불"** 로 표기합니다. 직접 예치는 전자금융거래법상 등록이 필요해서입니다.
- 공급자에게 돈을 받지 않으므로 정기결제는 필요 없습니다.

### 거래확정
- **리스트를 전달하면 거래가 이루어진 것으로 봅니다.**
- **검증기간 7일**: 수요자가 공급자에게 연락해 체크리스트와 맞는지 확인합니다.
- 7일 안에 이의가 없으면 **자동 확정**됩니다.

### 불일치 판정
| 경우 | 판정 | 수요자 처리 |
|---|---|---|
| **필수값**이 체크와 다름 (● 가능이라 했는데 불가 등) | **업체 불일치** | 그 업체분 환불 **또는** 대체 업체 (수요자 선택) |
| ▲ 조건부인데 적어 둔 조건으로도 안 됨 | 업체 불일치 | 위와 같음 |
| 연락 두절 (3영업일 동안 3번 넘게 연락해도 응답 없음, 번호 오류, 폐업) | 업체 불일치 | 위와 같음 |
| **조건값**만 다름 | 조건값 불일치 | 그 조건값 **추가요금만** 환불 |
| **범위 항목**(MOQ·단가·납기): 첫 상담 내용이 공급자가 답한 범위 **안** | 일치 | 없음 |
| 범위 항목: 첫 상담 내용이 공급자가 답한 범위를 **벗어남** | **업체 불일치** | 환불 또는 대체 |
| 범위 항목: 첫 상담 이후 협의 과정에서 바뀜 | 불인정 (협의로 확정하는 값) | 없음 |
| 수요자가 조건(수량·사양·납기)을 바꿈, 단순 변심, 7일 경과, 증빙 없음 | 불인정 | 없음 |

- **MOQ·단가·납기는 범위로 받습니다.** 수요자도 범위로 요청하고(예: 500~1,000개, 600~800원, 4~6주), 공급자도 범위로 답합니다. 최종 값은 두 사람이 협의해서 확정합니다. 불일치는 **"공급자가 답한 범위"** 를 기준으로 판단합니다.
- **±20%는 노출 기준입니다.** 공급자 범위가 수요자 범위와 겹치면 ●, 겹치지 않아도 수요자 범위의 ±20% 안이면 ▲로 **리스트에 올릴 수 있습니다.** ±20%를 벗어나면 ✕이고, 필수값 ✕이므로 제외됩니다.
- **업체 환불액** = 결제금액 × (불일치 업체 수 ÷ 전달한 업체 수). 전부 불일치면 전액을 환불합니다.
- 이의신청에는 증빙이 필수입니다: 업체, 항목, 실제로 들은 내용, 통화 일시, 문자나 견적서 캡처.
- **악용 방지**: 불일치로 환불받은 업체와 나중에 계약하면 환불액을 반환합니다. (약관에 명시)

### 업체가 부족할 때
- 응답한 공급자 중 조건에 맞는 업체가 요청 수보다 적으면, **브로커가 비회원 공급자를 직접 수배**해서 채웁니다.
- 그래도 모자라면 부족한 업체 수만큼 환불합니다.

## 4. 공급자

### 가입
- **사업자등록번호 진위확인 필수** (국세청 공공 API, 휴·폐업 여부 포함)
- 가입할 때 자기 분야(대분류·중분류·공정)와 **보유 인허가**를 고르면 **맞는 의뢰가 올라올 때 알림**을 받습니다.
- **노출 규칙**: 대분류는 필수, 중분류는 선택입니다. **설정하지 않으면 넓게 노출**합니다.
  - 수요자가 중분류를 정하지 않음 → 그 대분류의 공급자 **전체**에게 노출
  - 공급자가 중분류를 정하지 않음 → 그 대분류의 의뢰 **전체**를 봄
- 비용은 **무료**입니다.

### 공급사 둘러보기 (모두에게 공개)
- 업체명과 연락처를 **가린 프로필**만 보입니다: 분야, 지역(시·도), 가능 공정, 확인된 인증 배지, 응답 건수
- 수요자가 여기서 공급사를 골라 **지정 의뢰**를 보낼 수 있습니다.
- 신뢰도 점수는 여기서도 보이지 않습니다.

### 보이는 것 / 안 보이는 것
| 공급자에게 보임 | 공급자에게 안 보임 |
|---|---|
| 의뢰 내용 전부 (분류, 품목, 수량, 예산, 납기, 필수값, 조건값, 상세 설명) | **수요자 정보 전부** (회사명, 이름, 연락처, 이메일) |
| 본인 응답, **본인 신뢰도 점수** | 다른 공급자의 응답·단가·점수 |

- **회원가입한 공급자만** 의뢰를 볼 수 있습니다. 비회원은 볼 수 없고, 비회원 업체는 브로커가 대신 확인하고 응답을 입력합니다(대리 입력).
- 비회원에게는 **분야별 진행 중 의뢰 건수만** 보여 줍니다. 내용은 보이지 않습니다.
- 의뢰는 회원 누구나 볼 수 있지만, **분류와 설명을 자세히 나눠** 공급자가 맞는 의뢰만 골라 들어오게 합니다.

### 응답
- 공급자가 필수값·조건값마다 **● 가능 / ▲ 조건부 / ✕ 불가** 와 메모, 단가, MOQ, 납기를 입력해 제출합니다.
- 응답 기한은 **[예시] 의뢰 공개 후 48시간**입니다.
- 공급자 연락처는 **선정되어 리스트에 오를 때만** 수요자에게 공개됩니다.

## 4-1. 첨부 파일

- 수요자는 요청서에 참고 이미지, 도면, 디자인 파일을 여러 개 첨부할 수 있습니다.
- 파일마다 **공개 범위**를 정합니다.
  - **모두 공개**: 의뢰를 볼 수 있는 공급자 회원 전체
  - **선정사 공개**: 리스트에 선정된 공급자(지정 의뢰는 지정한 공급자)만
- **의뢰 목록 화면**에는 썸네일 **1개만** 보입니다. "모두 공개" 파일 중 첫 번째이고, 없으면 분야 기본 이미지를 씁니다.
- 상세 화면에 들어가면 공개 범위에 맞는 파일만 보입니다.
- 업로드할 때 **"파일에 회사명·로고·연락처가 보이면 수요자 정보가 드러날 수 있다"** 고 안내합니다.

## 5. 업체 선정

1. **필수값에 ✕ 불가가 하나라도 있으면 제외**합니다.
2. **순위 점수 = 체크리스트 적합도 70% + 신뢰도 점수 30% [예시]**
   - 적합도: 가능 1점, 조건부 0.5점, 확인한 항목 기준
3. 상위 **N곳**(수요자가 요청한 업체 수)을 브로커가 검증한 뒤 리스트로 전달합니다.
4. 수요자에게는 신뢰도 점수를 보여주지 않습니다. 적합도와 체크 결과만 보입니다.

## 6. 신뢰도 점수

**공개 범위: 공급자 본인과 운영자만** 볼 수 있습니다.

| 사유 | 점수 **[예시]** |
|---|---|
| 시작 | 100 |
| 필수값 불일치 (공급자 책임) | −10 |
| 조건값 불일치 (공급자 책임) | −3 |
| 연락 두절 | −15 |
| 의견서 기한 내 미제출 | −5 추가 |
| 검증기간 문제없이 통과 | +1 (최대 100) |

| 등급 **[예시]** | 점수 | 효과 |
|---|---|---|
| 우수 | 90 이상 | 우선 노출 |
| 일반 | 70~89 | 일반 |
| 주의 | 50~69 | 선정 후순위 |
| 제한 | 50 미만 | 응답 제한 (소명 후 해제) |

### 불일치가 나왔을 때 절차
1. 수요자의 이의가 접수되면 공급자에게 **의견서와 사유**를 요청합니다. 기한은 3영업일입니다.
2. 운영자가 판정합니다.
   - **공급자 책임**: 점수를 차감합니다.
   - **수요자가 조건을 바꿨거나 오해한 경우**: 차감하지 않고, 수요자 환불도 불인정합니다.
   - **불가항력**(원자재 급등, 설비 고장 등): 차감을 줄이거나 하지 않습니다.
3. **수요자 환불과 공급자 차감은 따로 판단합니다.** 수요자에게 환불하더라도 공급자 점수는 깎지 않을 수 있습니다.

|---|---|
| 대분류 | 분야 |
| 중분류 | 품목. **선택 사항, 무료.** 고르지 않으면 대분류 전체에 노출 |
| 공정 | 가능 공정 (공급자 가입 시 선택) |
| 필수값 템플릿 | **대분류마다** 고정. 요청서에 자동으로 포함. MOQ·단가·납기는 **범위 입력** |
| 조건값 목록 | 선택 목록. 고르는 만큼 추가요금 (1개당 5,000원) |
| 법정 인허가 | **대분류 단위** 인허가(예: 식품 제조업)는 필수값, 무료. **중분류 단위** 인허가(예: 펫 간식의 사료제조업)는 **기본 전제**로, 공급자가 응답할 때 보유를 서약. 수요자가 **서류로 확인**받고 싶으면 권장 조건값으로 +5,000원 |

**처음 자세히 만들 분야: 식품 OEM, 반려동물용품, 패키지·인쇄.** 나머지 분야는 대분류만 두고, 의뢰가 들어오는 대로 넓힙니다. 세부 분류표는 수정 작업 때 대표님 거래처 경험을 바탕으로 따로 만듭니다.

## 7-1. 온라인 기본계약서 (계약 사실 기록)

수요자와 공급자가 거래하기로 하면, **사이트에서 기본계약서를 작성하고 양쪽이 전자서명**합니다. 우리는 그 계약서를 보관하고 **"이런 계약이 있었다는 것"을 기록·확인**합니다.

| 항목 | 내용 |
|---|---|
| 목적 | 양쪽이 계약 내용을 다르게 해석하거나 분쟁이 생겼을 때 기준 문서를 남겨 **분쟁을 줄임**. 수요자에게는 **회원가입 이유**가 됨 |
| 우리 역할 | 표준 양식 제공, 서명 절차, 원본 보관, **계약 사실 확인서** 발급. **보증하지 않음, 거래 당사자 아님** |
| 명칭 | "공증"은 공증인만 쓸 수 있는 용어라 **"계약 사실 기록·확인"** 으로 표기 |
| 대상 | 수요자와 공급자 **모두 회원** (수요자도 회원가입 필요) |
| 비용 | **무료.** 브로커 역할을 자동으로 처리할 수 있는 단계가 될 때까지 무료 |

**흐름**
1. 리스트에서 공급자를 정하고 협의를 마치면, 둘 중 한쪽이 **기본계약서 작성**을 시작합니다.
2. 표준 조항에 이번 거래 내용을 채웁니다: 품목, 사양, 수량, 단가, 납기, 대금 지급 조건, 검수·하자 처리, 해지, 분쟁 해결.
3. 상대방이 확인하고 수정을 요청하거나 동의합니다.
4. **양쪽이 휴대폰 본인인증으로 서명**합니다.
5. 서명이 끝나면 PDF를 만들고, **위변조 확인값(해시)과 서명 시각**을 함께 보관합니다. 양쪽 모두 내려받을 수 있습니다.
6. 필요할 때 우리가 **계약 사실 확인서**(계약 당사자, 서명 일시, 문서 확인값)를 발급합니다.

**참고**
- 전자서명법상 전자서명도 효력이 있습니다. 본인인증을 거치면 "누가 서명했는지" 증명이 강해집니다. 본인인증은 건당 수십 원 수준의 비용이 듭니다.
- 제조를 맡기는 거래는 규모에 따라 **하도급법의 서면 발급 의무**가 적용될 수 있습니다. 기본계약서가 그 서면 역할을 할 수 있도록 필수 기재사항을 양식에 넣습니다.
- 계약이 체결되면 우리도 **실제 성사율 데이터**를 얻습니다. 나중에 공급자 신뢰도에 "계약 이행"을 반영할 수도 있습니다.
- 표준 양식과 확인서 문구는 **변호사 검토**를 받습니다.

## 10. 보류·추후 결정

- 추가요금 세부 조정 (조건값은 일단 전부 5,000원, 업체 추가 20,000원은 예시)
- 기본계약서 유료화 시점 (브로커 자동화 이후), 표준 양식 변호사 검토
- 카테고리 세부 분류 (데이터를 모으며 계속 수정)
- 점수표·등급·순위 비율 (예시대로 운영하며 조정)
- 공급자 응답 기한 (예시 48시간)
- 부가세 포함/별도
- 공급자 유료화 시점과 방식 (단계 전환 기준은 일단 생략)
- 카카오톡 채널 (홈페이지 오픈 후)
- 홈페이지 주소 (홈페이지 작업 후)
- 통신판매업 신고, 약관·계약서 변호사 검토
