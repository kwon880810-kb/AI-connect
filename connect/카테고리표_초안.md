# 카테고리표 초안 (식품 OEM · 반려동물용품 · 패키지·인쇄)

> 초안 2026-11-05. `BM_확정안.md` 7번(카테고리)의 세부안입니다. 확정되면 요청서·공급자 가입·응답 화면과 DB가 이 표를 그대로 씁니다.
> 고칠 곳은 표에 직접 표시하거나 번호로 말씀해 주세요. 인허가 명칭은 실제 운영 전에 한 번 더 확인이 필요합니다.

## 0. 구조

```
대분류 (분야)
 ├ 필수값 = 공통 필수 + 대분류 필수 + (해당되면) 중분류 추가 필수   → 착수금에 포함
 ├ 중분류 (품목)
 │   └ 조건값 목록 → 수요자가 고른 만큼 추가요금
 └ 공정 목록 → 공급자가 가입할 때 "할 수 있는 공정"으로 선택
```

**확정안과 달라지는 점**: 확정안은 "필수값은 대분류마다 고정"이었습니다. 그런데 같은 반려동물용품이어도 **간식은 사료제조업 등록이 꼭 필요하고 장난감은 필요 없습니다.** 그래서 **중분류 추가 필수**를 두는 것을 제안합니다. (질문 1)

### 응답 방식
체크리스트 항목은 두 종류로 나눕니다.

| 종류 | 공급자 입력 | 쓰임 |
|---|---|---|
| **값 입력형** | 숫자·기간 입력 (예: MOQ 500개, 단가 650원, 납기 4주) | 수요자 요청값과 **자동 비교** → ● / ▲ / ✕ 자동 판정, 단가 ±20% 오차 판정에도 사용 |
| **선택형** | ● 가능 / ▲ 조건부(조건 메모 필수) / ✕ 불가 | 인증·공정·지원 여부 |

값 입력형으로 받으면 브로커가 일일이 판정하지 않아도 되고, 나중에 불일치가 생겼을 때 **"공급자가 무엇이라고 답했는지"가 숫자로 남아** 판정이 쉬워집니다. (질문 2)

## 1. 공통 필수값 (모든 분야)

| # | 항목 | 수요자 입력 | 공급자 응답 | 형식 |
|---|---|---|---|---|
| C1 | 최소 주문 수량 (MOQ) | 희망 수량 | 최소 가능 수량 | 값 입력 |
| C2 | 예상 단가 | 예산 단가 (선택) | 요청 수량 기준 단가 | 값 입력 |
| C3 | 생산 납기 | 희망 납기 | 발주 후 생산 기간 | 값 입력 |
| C4 | 샘플(시제품) | 필요 여부 | 가능 여부, 비용, 기간 | 선택 + 값 |
| C5 | 공장 위치·납품 방법 | 납품지 (시·도) | 공장 시·도, 배송 방법(택배/화물/직접) | 선택 + 메모 |

## 2. 식품 OEM

**대분류 필수**
| # | 항목 | 형식 |
|---|---|---|
| F1 | 식품 제조 인허가 보유 (식품제조·가공업 등, 품목에 맞는 영업 등록) | 선택 |
| F2 | 요청 품목의 생산 이력 (같거나 비슷한 제품을 만들어 본 적 있는지) | 선택 + 메모 |

**중분류와 조건값**
| 중분류 | 추가 필수 | 조건값 (선택 시 추가요금) |
|---|---|---|
| 소스·드레싱·조미료 | – | 액상 충진 용량 대응, 병입/파우치/스틱, 상온 유통 |
| 건조식품·분말·차 | – | 스틱 포장, 티백, 분말 입도 조절 |
| 음료·액상차 | – | 병/캔/파우치, 살균 방식(레토르트·고온), 소용량 |
| 과자·베이커리·떡 | – | 개별 포장, 냉동 유통, 모양틀 제작 |
| 육가공·수산가공 | – | 냉장·냉동 출고, 진공 포장 |
| 간편식·냉동식품 | – | 레토르트, 급속 냉동, 전자레인지 용기 |
| 잼·청·절임 | – | 병입, 당도 조절, 무첨가 |
| 건강기능식품 | **건강기능식품 제조업 허가 + GMP** | 정·캡슐·환·젤리 제형, 기능성 원료 인정 서류 |

**식품 공통 조건값** (모든 중분류에서 고를 수 있음)
HACCP 인증 · 유기농/비건/할랄 인증 · 레시피 개발(ODM) · 품목제조보고 대행 · 자가품질검사·영양성분 분석 대행 · 원료 직접 수급 · 소비기한 ○개월 이상 · 패키지 디자인 지원 · 정기(월 단위) 생산 · 수출 서류 대응 · 물류창고 직납

**공정** (공급자 가입 시 선택)
혼합 · 가열·살균 · 레토르트 · 건조 · 동결건조 · 분쇄·분말 · 액상 충진 · 분말 충진 · 스틱 포장 · 파우치 실링 · 병입 · 캔 · 성형 · 급속 냉동 · 진공 포장

## 4. 패키지·인쇄

**대분류 필수**
| # | 항목 | 형식 |
|---|---|---|
| K1 | 요청 사양의 인쇄 방식 보유 (도수, 지류·소재) | 선택 + 메모 |

**중분류와 조건값**
| 중분류 | 추가 필수 | 조건값 |
|---|---|---|
| 택배 박스 (골판지) | – | 맞춤 규격 · 이중골 · 내부 칸막이 · 무지 박스 |
| 단상자 (지함·싸바리 포함) | – | 창문(투명 필름) · 자석 개폐 · 내부 트레이 |
| 스티커·라벨 | – | 롤 라벨(자동 부착기용) · 방수 · 투명·은박 소재 |

| 리플렛·카드·인쇄물 | – | 접지 · 넘버링 · 가변 데이터(QR·이름) |

## 5. 나머지 분야 (대분류만, 추후 세분화)
생활·잡화 · 화장품 · 부자재·판촉물 · 포장·조립·키팅 · 물류(보관·출고)

이 분야들은 **공통 필수값(C1~C5)만** 적용하고, 조건값은 수요자가 직접 쓰게 합니다. 의뢰가 쌓이면 자주 나오는 질문을 조건값 목록으로 올립니다.

## 확인해 주실 것
1. **중분류 추가 필수**를 둘지 (간식은 사료제조업, 건강기능식품은 GMP 등)
2. MOQ·단가·납기를 **값 입력형**으로 받아 자동 판정할지
3. 중분류·조건값·공정 중에 **빼거나 더할 것** (대표님 거래처 경험 기준)
4. 조건값 추가요금을 **전부 같은 금액**(예시 5,000원)으로 할지, 인증처럼 확인이 어려운 항목은 더 비싸게 할지
