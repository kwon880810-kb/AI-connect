# 카테고리표 (1차안)

> 1차안 2026-11-05. `BM_확정안.md` 7번(카테고리)의 세부안입니다.
> 처음부터 완벽하게 나누는 것이 목적이 아니라, **수요자가 헷갈려도 맞는 공급자에게 닿게 하는 것**이 목적입니다. 의뢰 데이터가 쌓이는 대로 계속 고칩니다(6번 참고).
> 인허가 명칭과 적용 범위는 운영 전에 관계 기관 확인이 필요합니다. 아래 "헷갈리기 쉬운 점"은 **분류 안내용**이며 법률 판단이 아닙니다.

### 표 읽는 법
- **별칭·검색어**: 수요자가 실제로 쓰는 말입니다. 요청서에 "만들고 싶은 것"을 입력하면 이 단어로 **분류를 추천**합니다.
- **헷갈리기 쉬운 점**: 수요자가 잘못 고르기 쉬운 경우입니다. 해당 중분류를 고르면 화면에 안내를 띄우고, 브로커가 검토할 때도 참고합니다.
- **권장 (서류 확인)**: 법적으로 필요한 인허가입니다. 기본 전제이므로 따로 고르지 않아도 공급자 서약 대상이고, 서류로 확인받으려면 5,000원입니다.

## 6. 계속 고치는 방법 (데이터 모으기)

분류는 처음 정한 표보다 **실제로 들어오는 의뢰**가 더 정확합니다. 다음 네 가지를 자동으로 쌓아 두고 **한 달에 한 번** 정리합니다.

| 쌓는 데이터 | 어디서 | 쓰임 |
|---|---|---|
| 수요자가 쓴 "만들고 싶은 것" 원문 | 요청서 | 새 **별칭·검색어** 추가 |
| 수요자가 고른 분류 → 브로커가 바꾼 분류 | 관리자 검토 | **"헷갈리기 쉬운 점"** 추가, 분류 추천 개선 |
| 수요자가 직접 쓴 조건 | 요청서 기타 조건 | 자주 나오면 **조건값 목록**으로 |
| 공급자가 응답을 거절한 사유 | 공급자 응답 | 분류가 너무 넓은 곳을 **중분류로 쪼갬** |

- 관리자 화면에 **"분류 변경"** 기능을 두고, 바꿀 때마다 "원래 분류 → 바꾼 분류"를 기록합니다.
- 분류표는 DB에 넣어 **화면 수정 없이** 관리자 화면에서 추가·수정할 수 있게 만듭니다.
