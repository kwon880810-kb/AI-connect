# 출시 프로젝트 설계 (2026-11-05 합의안)

> 의뢰서를 "공장 한 곳 찾기"에서 **"아이디어를 출시까지 데려가는 프로젝트"** 로 넓힙니다.
> 이 문서는 `BM_확정안.md`에 추가되는 내용이며, 겹치는 부분은 이 문서가 우선합니다.
> **[확인 필요]** 표시는 대표님 확인 후 확정합니다.

---

## 1. 큰 구조

```
총 프로젝트 (아이디어 1개)
 ├ 1차   1~2단계  아이디어·컨셉, 제품 생산        → 샘플/제품 받기
 ├ 2차   3~5단계  포장 형태, 포장 디자인, 포장재 제작
 ├ 2-1차 6단계    표시사항·인증 (필수 품목은 필수, 아니면 생략)
 ├ 3차   7·9단계  촬영·상세페이지, 판매 채널
 └ 4차   8단계    물류
```

- 각 차수가 끝나면 **"여기서 마치기 / 다음 차수 이어하기 / 새 아이디어로 다시 시작"** 중에서 고릅니다.
- 샘플을 받아 보고 아니다 싶거나 새 아이디어가 나오면 **다시 시작**할 수 있습니다.
- 앞 차수에서 연결된 제작 파트너는 다음 차수에도 이어집니다. 예를 들어 생산 공장에 포장재나 물류 가능 여부를 물어볼 수 있습니다.
- 의뢰서는 **언제든 임시저장**되고(자동 저장 + 버튼), '내 프로젝트'에서 이어서 작성합니다.

## 2. 단계별 선택지

모든 선택지 옆에 **(?)** 를 두고, 누르면 짧은 설명이 뜹니다.

| 단계 | 선택지 |
|---|---|
| **1. 아이디어·컨셉** | 설명만 적기 / 내 스케치·이미지 올리기 / AI 도구로 만든 이미지 올리기 |
| | └ 아래에 **AI 이미지 도구 링크 목록**과 **저작권·상업적 이용 안내** |
| | └ "**AI 컨셉 이미지 생성 기능 업데이트 예정** — 이후에는 1단계가 한 페이지에서 끝납니다" |
| **2. 제품 생산** | OEM (내 사양대로 생산) / ODM (레시피·설계까지 공장이) / 이미 거래처 있음 |
| **3. 포장 형태** | 단상자 / 파우치 / 병·용기 / 라벨만 / 추천받기 |
| **4. 포장 디자인** | 직접 디자인 / AI 도구 활용 (? 안에 예시 도구) / 컨셉만 정하고 디자이너에게 / 완성 디자인 있음 |
| **5. 포장재 제작** | 생산 공장에서 함께 / 별도 업체 견적받기 / 이미 있음 / 나중에 |
| **6. 표시사항·인증** | 필요 없음 / 직접 / 대행 |
| | └ 분야별 **필요한 인증·신고 안내** 문구 (아래 4번) |
| **7. 촬영·상세페이지** | 직접 / 촬영만 맡기기 / 상세페이지까지 맡기기 |
| **8. 물류** | 직접 발송 / 3PL 견적받기 / 생산 공장에서 가능한지 문의하기 |
| **9. 희망 판매 채널** | 체크박스 (여러 개 선택), 아래 5번 목록 |

"견적받기", "디자이너에게", "대행", "맡기기"를 고른 단계는 지금의 의뢰 흐름(체크리스트 → 파트너 응답 → 선정 → 7일 검증)을 그대로 탑니다.

## 3. AI 이미지 도구 (링크만 제공, 플랫폼에서 생성하지 않음)

| 도구 | 특징 (안내 문구용) |
|---|---|
| ChatGPT (OpenAI) | 대화하듯 설명하면 이미지 생성, 수정 요청이 쉬움 |
| Google Gemini | 이미지 생성·편집, 구글 계정으로 바로 사용 |
| Adobe Firefly | 상업적 이용을 염두에 두고 학습한 모델, 포토샵과 연동 |
| Canva (매직 미디어) | 생성한 이미지를 바로 포장·상세페이지 디자인에 사용 |
| Microsoft Designer / Copilot | 무료로 시작하기 쉬움 |
| Ideogram | 이미지 안에 글자(제품명·로고) 넣기에 강함 |
| Midjourney | 분위기·컨셉 이미지 품질이 높음 (유료) |
| Leonardo.ai | 제품 목업·컨셉 시안용 |

**안내 문구 (요지)**
- AI 이미지는 **컨셉을 전달하는 참고 시안**입니다. 공장·인쇄소가 그대로 만들 수 있는 도면이 아니며, 실제 포장 디자인은 규격·칼선에 맞춰 다시 작업해야 합니다.
- **상업적 이용 가능 여부는 도구와 요금제마다 다릅니다.** 판매 제품에 쓰기 전에 각 도구의 이용약관을 확인하세요.
- AI로 만든 이미지는 **저작권 보호를 받기 어려울 수 있습니다.** 다른 사람이 비슷하게 써도 막기 어렵습니다.
- 다른 브랜드의 **상표·캐릭터·디자인과 비슷하면 침해**가 될 수 있으며, 그 책임은 이미지를 올린 분에게 있습니다.
- 올린 컨셉 이미지는 기본적으로 **선정된 파트너에게만** 공개됩니다.

## 6. 요금 (2026-11-05 확정)

| 시점 | 금액 | 설명 |
|---|---|---|
| **첫 파트너 찾기 접수** (보통 1차) | **접수비 9,900원** (초기 쿠폰이면 0원) | 제작 파트너에게 공개되는 조건. 응답이 한 곳도 없으면 환불 |
| **첫 리스트 받을 때** | **착수금 50,000원** + 추가 조건(개당 5,000원) + 업체 추가(1곳당 20,000원) | 접수비와 **별도**. 연락처 공개. **총 프로젝트당 1회** |
| **이어하기** (같은 총 프로젝트의 다음 차수에서 새 파트너 찾기 1건마다) | **9,900원** + 추가 조건(개당 5,000원) + 업체 추가 요금 | 착수금은 다시 받지 않음 |
| 이미 연결된 파트너와 계속 진행 | **0원** | 예: 1차 공장에 포장재·물류 가능 여부 문의, 같은 공장에 샘플 다시 요청 |
| 샘플 후 다시 시작, **같은 공장** | **0원** | 같은 총 프로젝트에서 사양을 고쳐 다시 진행 |
| 샘플 후 다시 시작, **새 공장 찾기** | 이어하기 요금 (9,900원 + 추가 요금) | |
| 완전히 새 아이디어 | 새 총 프로젝트 | 접수비 + 착수금 처음부터 |

- **중간 차수부터 시작 가능**: 이미 제품이 있으면 2단계를 "이미 거래처 있음"으로 넘기고 2차·4차부터 시작합니다. 그 프로젝트의 **첫 파트너 찾기**에 접수비와 착수금이 적용되고, 이후는 이어하기 요금입니다.
- **지정 의뢰** (둘러보기에서 직접 고른 파트너에게): 착수금 절반(25,000원). 접수비 9,900원은 같음. **[확인 필요: 기존 결정 유지로 가정]**
- **초기 1만 원 쿠폰**: 접수비에만 적용. 1인 1장(휴대폰 번호 기준), 사용 기한 있음, 동시에 1건만 무료. 종료 시점은 따로 정함.
- 금액은 모두 관리자 화면의 **요금 설정**에서 바꿀 수 있게 만듭니다.

## 7. 운영사(KB물류)와 3PL
- 3PL은 **다른 3PL 사업자도 제작 파트너로 가입**할 수 있습니다.
- KB물류는 별도 사업자로 참여합니다. 홈페이지 소개말에 **대표자의 물류 운영 경력** 정도로만 표현합니다.

## 8. 제작 파트너 가입 조건
- **사업자등록이 있는 업체·프리랜서만** 가입합니다. 디자이너, 촬영, 상세페이지, 인증 대행도 마찬가지입니다.
- 사업자 없는 개인은 패널티와 제한을 빠져나갈 수 있어 받지 않습니다.
